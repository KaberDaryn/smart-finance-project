# Research protocol and desk review

## Desk review

The review considered public product descriptions, not hands-on usability measurements. Sources were accessed on 19 October 2026.

Spendee describes manual expense recording, spending charts, category budgets, and budget reminders. These features support keeping recording, understanding, and planning close together. Source: [Spendee official product page](https://www.spendee.com/).

Wallet by BudgetBakers describes manual entry, automatic categorisation, bank imports, and visual spending analytics. This indicates that category review and transaction capture are common parts of the workflow. Smart Finance limits import to CSV and makes its category suggestion optional. Source: [Wallet official expense-tracking page](https://budgetbakers.com/en/products/wallet/features/expense-tracking/).

These observations informed the feature scope. They do not demonstrate that the prototype is more usable, more accurate, or more secure than those products.

## Research questions

- Can a new user record an expense without help?
- Does the user understand the difference between balance, budgets, and saved goal progress?
- Can a user find and correct a suggested category before saving?
- Are the forecast limitations and incomplete-history behaviour understood?

## Interview and usability protocol

The pilot protocol covers 3-5 consenting adults who already track some personal spending. Use fictional transactions throughout the session. Do not ask for bank credentials or personal financial records. Record an anonymous participant ID and device class; names are unnecessary.

Interview prompts: How do you currently record expenses? What makes you stop doing it? Which totals do you check most often? What do you expect a budget warning to mean? When would you trust a suggested category?

Tasks: create a test account; add a 1500.00 KZT grocery expense; find it with search; set an 1000.00 KZT grocery budget; explain the overspending message; create a 10000.00 KZT goal and record 2500.00 saved; request a category suggestion; explain an expense forecast.

For each task record completion without help, completion time, errors, assistance, and the participant's own explanation. Ask for a 1-5 ease rating and one improvement after each task. Summarise recurring problems without treating this convenience sample as representative.
